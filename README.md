# Verdadeiro ou Falso · demo web

Build WebGL da demo do **Verdadeiro ou Falso**, da Suricatus Games, publicada pelo GitHub Pages em
https://suricatus.github.io/verdadeiro-ou-falso/ e exibida em https://suricatusgames.com/demos/.

Este repositório guarda só a build. Ela é gerada no projeto Unity pelo menu
**Suricatus > Build WebGL (demo do site)**, que grava a pasta `docs/`; o conteúdo dessa pasta é o
que fica aqui na raiz.
